# Pruebas Numéricas — Tesis

Este repositorio contiene el código utilizado para realizar pruebas numéricas 
de la dinámica de una función racional sobre campos p-ádicos, como parte de 
mi tesis de licenciatura en la carrera de Matemáticas en la UNAM.

## Contenido
- `PolinomioCuadratico.jl`: Simulaciones para el conjunto de Julia de un polinomio cuadratico de la forma $\phi(z)=z^2+\lambda z$ en el campo $\mathbb{Q}_2$.
- `PolinomioDeGradoP.jl`: Simulaciones para el conjunto de julia del polinomio $\phi(z)=\frac{z^{p}-z}{p}$ en el campo $\mathbb{Q}_p$

## Contexto
Los resultados obtenidos son consistentes con lo encontrado en la tesis.
